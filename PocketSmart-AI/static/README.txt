PocketSmart AI - Static Assets Directory
=========================================

This directory contains static media and assets used by the PocketSmart AI application.

Suggested contents:
- app_icon.png: Application logo / favicon
- demo_outfit.jpg: Sample outfit image for testing the AI Jewellery Matcher
- banner.png: Promotional or dashboard header banner

All files placed in this folder can be referenced by Streamlit or local utilities.
